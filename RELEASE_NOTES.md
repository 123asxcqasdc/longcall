LongCall 98 — аудиозвонки до 4 человек в оформлении Windows 9x. Версия 1.2.0: веб-версия и настольное приложение для Windows и Linux.

## Установка

**Windows · установщик** — `longcall98-1.2.0-setup.exe`. Классический мастер в стиле Win98: боковая панель, «Добро пожаловать в мастер установки LongCall 98», выбор папки, ярлыки на рабочем столе и в «Пуске».
Сборка не подписана, поэтому SmartScreen может показать «Неизвестный издатель»: «Подробнее» → «Выполнить в любом случае».

**Windows · без установки** — `longcall98-1.2.0-portable.exe`, можно держать на флешке.

**Linux · AppImage** — ничего ставить не нужно:

```bash
chmod +x longcall98-1.2.0-x86_64.AppImage
./longcall98-1.2.0-x86_64.AppImage
```

**Linux · deb** (Debian, Ubuntu, Mint и производные):

```bash
sudo apt install ./longcall98-1.2.0-amd64.deb
```

## Что нового в 1.2.0

- **Чат прямо в звонке.** Кнопка «Чат» на панели звонка занимает место журнала:
  история сообщений, поле ввода, «Отправить». Пригодится, когда микрофон выключен,
  говорить неудобно или связь плохая. Новое сообщение у закрытой панели поднимает
  счётчик на кнопке и подаёт короткий сигнал. До 500 символов, не чаще одного
  сообщения в секунду, видны последние 80.
- **`Ctrl+V` и перетаскивание.** Скриншот из буфера или файл, брошенный в окно,
  уходят в звонок тем же путём, что и через «Файлы»: полоса прогресса, «Отменить»,
  очередь по одному. Обычный текст вставляется как раньше — перехватываются только
  файлы.
- **Своё оформление.** «Вид → Своё оформление…»: поле для собственного CSS поверх
  стандартного вида. Применяется сразу, хранится в браузере (`lc.css`) и
  восстанавливается при следующем запуске ещё до отрисовки. Есть кнопка «Очистить»
  и адрес `?nocss`, если эксперименты сломали интерфейс. Скрипты не исполняются.
- На главном экране появился счётчик непрочитанных сообщений чата; при смене языка
  чат перерисовывается вместе с остальным интерфейсом.

## Что нового в 1.1.0

- **Передача файлов прямо в звонке.** Кнопка «Файлы» на панели звонка: отправка, прогресс с отменой, список файлов всех участников, «Скачать» и «Удалить». Файлы лежат в Firebase рядом с комнатой и исчезают вместе с ней.
- Один файл за раз — так честнее считать прогресс и не забивать канал; до 8 МБ на файл и до 12 файлов на комнату.
- В настольном приложении файл сохраняется через системный диалог «Сохранить как», а не молча в «Загрузки».
- Новый файл отмечается в журнале звонка и всплывающим уведомлением; на кнопке появляется счётчик.
- **Просмотр без скачивания.** Кнопка «Просмотр» или клик по имени файла: картинки (png, jpg, gif, webp, bmp, svg — с размерами в пикселях), mp4/webm — плеером, mp3/wav — плеером, txt и прочий текст — в окне. Старые блокнотные файлы в Windows-1251 читаются нормально.
- Полоса загрузки больше не остаётся на экране после подключения всех участников.
- Приложение переехало на свой домен **longcall.c6t.ru**; ссылки на комнаты теперь
  выглядят как `https://longcall.c6t.ru/?room=1234`.

## Что нового в 1.0.3

- **TURN снова работает.** Metered отключил старый публичный логин `openrelayproject` — теперь креды подписываются в браузере через WebCrypto (HMAC-SHA1, срок 12 часов), порты 80/443 и TLS. Плюс запасной ретранслятор.
- **Отчёты о проблемах.** Если соединение не установилось, приложение само отправляет подробный отчёт в Firebase: платформа, ICE-серверы без паролей, типы кандидатов, таймлайн состояний и `getStats()` — видно, выбрана ли пара через relay. Вручную: «Справка → Отправить отчёт».
- В журнале звонка появилась строка `канал: relay (udp)` — сразу видно, идёт ли звук через ретранслятор.

## Что нового в 1.0.2

- **Звонки между городами проходят**: добавлен TURN-ретранслятор (публичный бесплатный Open Relay, порты 80/443, TCP и TLS). STUN сам по себе не помогает за симметричным NAT и в мобильных сетях.
- **Панель окна на Linux**: настоящая панель с названием и кнопками, перетаскивание работает и под Wayland; окно больше не может открыться за краем экрана и потерять заголовок.
- В журнале звонка видно, какие ICE-кандидаты собрались; при недоступном ретрансляторе показывается понятная подсказка вместо «connection failed».

## Что нового в 1.0.1

- Ссылка на комнату копируется как обычный адрес сайта (`https://…/?room=1234`), а не внутренний `app://`.
- Открытие комнаты в приложении по ссылке `longcall://`: кнопка «В приложении» в окне звонка и в приглашении, регистрация схемы в системе (в том числе для AppImage и portable-сборки), поддержка ссылок вида `longcall://join?room=1234`, `longcall://1234` и старых `--room=1234`.
- Экран загрузки снова показывается в настольной версии; главный экран появляется уже подключённым.
- Установщик Windows оформлен как мастер Windows 98.
- Заметки релиза больше не дублируются при пересборке.

## Что внутри

- В настольной версии нет «рабочего стола» и панели задач: каждое окно — настоящее окно системы, без системной рамки, с заголовком в стиле Win98 (перетаскивание за заголовок, двойной клик — развернуть).
- При запуске — тот же экран загрузки, что в браузере: окно «LongCall 98» с синим прогресс-баром; главный экран появляется уже подключённым.
- Главное окно и отдельное окно на каждый звонок; номер комнаты — 4 цифры.
- До 4 участников, только звук: WebRTC full-mesh, сигналинг Firebase Realtime Database.
- Локальный аккаунт без пароля, история недавних звонков по аккаунту, переключатель RU/EN.
- Обмен файлами до 8 МБ в звонке: файлы хранятся в Firebase и удаляются при закрытии комнаты.
- Ссылка на комнату копируется в виде обычного адреса сайта и всегда открывается в браузере; кнопка «Открыть в приложении» передаёт комнату установленному приложению по схеме `longcall://`.
- Закрытие окна звонка корректно выводит из комнаты, микрофон запрашивается один раз.

## Обновление с 1.1.0

В `database.rules.json` добавлен узел `chat`. Если правила заливались раньше, их нужно
задеплоить заново — иначе чат ответит «Firebase отклонил сообщение»:

```bash
firebase deploy --only database
```

Проще: Firebase Console → Realtime Database → Rules → заменить содержимое на
`database.rules.json` → Publish. Файлы и звонки работают и без этого обновления.
